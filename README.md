# Rollcasters Releases

Official Rollcasters desktop installers and cryptographically signed Tauri update artifacts.

This repository is release-only. Player artifacts are assembled as unpublished drafts by the protected Stable workflow in [`pmarshall7516/rollcasters`](https://github.com/pmarshall7516/rollcasters), then published only after the manual release gates and explicit owner approval pass.

Source code, master art, private signing keys, Catalog authoring data, and credentials do not belong in this repository.
